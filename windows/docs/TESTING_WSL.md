# WSL の Claude に貼る、表示のテスト用メッセージ

Coucou の新しい表示を、1つずつ確かめるための文言です。**WSL のターミナルで `claude` を起動して**、
上から順に、1つずつ貼ってください。

- どれも `~/coucou-test/` の中だけで作業します (消しても困らないフォルダです)。
- 差分を出すために、**`Write` / `Edit` ツールを使わせる**文言にしてあります (`sed` や `echo` だと出ません)。
- 権限確認が出たら、島の「許可」を押してください (これも確認項目です)。
- 一番下の「後片付け」で、テスト用のファイルを消せます。

---

## ① 基本の差分 (赤・緑・行番号・前後の行)

```
~/coucou-test/ フォルダを作って、その中に invoice.ts を Write ツールで作ってください。
中身は 12 行くらいで、`const TVA = 0.196` という行と、// コメントと、`total(items)` という関数を含めてください。
そのあと、Edit ツールで `const TVA = 0.196` だけを `const TVA = 0.20  // 2026` に書き換えてください。
sed や echo は使わず、必ず Write と Edit のツールを使ってください。終わったら一言で報告してください。
```

**確認すること**
- 概要のセッション名の横に **「差分 +1 −1」** のボタンが出る
- 押すと差分の画面が開く。赤 (削除、取り消し線) と緑 (追加)、**行番号**、**前後3行のコード**
- 左に `書き込み ✓ / 編集 ✓` のステップ。コードが色分けされている (コメントは緑がかった灰色、文字列は橙)
- 右上に `+1 −1` と `proj/…/invoice.ts` のパス

---

## ② 離れた2か所を同時に (区切り `⋯`)

```
~/coucou-test/invoice.ts を、MultiEdit ツールで離れた2か所を同時に書き換えてください
(1か所目は関数名を total から calcTotal に、2か所目は一番下に // end という行を足す)。
MultiEdit が使えなければ、Edit ツールを2回に分けて使ってください。sed は使わないでください。
```

**確認すること**
- 2つの変更のあいだに **`⋯`** の区切り行が出る (MultiEdit のとき)
- `Edit` を2回にしたときは、履歴に「編集 · invoice.ts」の行が2つ並ぶ

---

## ③ 複数ファイル (タブ)

```
~/coucou-test/ に、次の3つのファイルを Write ツールで作ってください。
- utils.py (def を2つと、# コメントと、文字列と数字を含める)
- README.md (見出しと箇条書きを少し)
- config.json (キーを3つ)
そのあと、それぞれ Edit ツールで1行ずつ書き換えてください。
Write と Edit のツールだけを使い、終わったら一言で報告してください。
```

**確認すること**
- 差分の画面の上に、**ファイルのタブ** (`PY utils.py` / `MD README.md` / `{} config.json` と、前の `TS invoice.ts`) が並ぶ
- タブを押すと、そのファイルの差分に切り替わる (最大4つまで)
- 拡張子ごとの**色分け** (`.py` のコメント、`.json` の true / null など)

---

## ④ コマンドの結果 (成功と失敗)

```
~/coucou-test/invoice.ts の `const TVA` の行を Edit ツールで 0.21 に書き換えてください。
そのあと、Bash ツールで次のコマンドを実行してください (テストの出力の真似です):
node -e "console.log('PASS tests/invoice.test.ts\n✓ applique la TVA (3 ms)\nTests: 3 passed, 3 total')"
```

続けて、失敗の見え方も確かめます。

```
もう一度、invoice.ts の `const TVA` の行を Edit ツールで 0.22 にしてください。
そのあと、Bash ツールで次を実行してください:
node -e "console.log('FAIL tests/invoice.test.ts\n✗ expected 22 got 21\nTests: 1 failed, 2 passed, 3 total')"
```

**確認すること**
- 差分の画面の下に、`$ node -e …` と**出力が3行まで**出る
- `PASS` / `✓` / `passed` の行は**緑**、`FAIL` / `✗` の行は**赤**
- 広げる (下に引く) と、出力が5行まで出る

## ⑤ 長いファイル (切り詰め)

```
~/coucou-test/big.txt を Write ツールで作ってください。中身は `row 1` から `row 300` まで、1行に1つずつです。
作ったら、Edit ツールで `row 150` を `row 150 (changed)` に書き換えてください。
```

**確認すること**
- 新規ファイルのとき、先頭から約160行で切れて、最後に **「… ほか N 行」** と出る
- `row 150` の編集は、行番号 (150) つきで、前後3行と一緒に出る

---

## ⑥ 機密ファイルは出さない

```
~/coucou-test/.env を Write ツールで作ってください。中身は `FAKE_KEY=abc123` の1行だけです (ダミーです)。
そのあと Edit ツールで `abc123` を `xyz789` に書き換えてください。
```

**確認すること**
- 権限確認のカードが**赤い警告** (「⚠ 機密ファイル」) で出て、「常に許可」が出ない
- 差分の画面は中身を出さず、**「非表示: 機密ファイルです。」** と出る (`FAKE_KEY` も `abc123` も見えない)

---

## ⑦ リアルタイム表示 (自動で開く)

先に、Coucou の**設定 → 一般 → 「ファイル編集をリアルタイム表示」をオン**にして、**島を閉じた状態**にしてください。

```
~/coucou-test/invoice.ts を Edit ツールで3回続けて書き換えてください
(1回目: TVA の行のコメントを // 2027 に、2回目: 関数名を calcTotal2 に、3回目: 一番下に // fin を足す)。
1回ごとに少し間を置かずに、続けてやってください。sed は使わないでください。
```

**確認すること**
- 編集のたびに島が**自動で開いて**差分が出る (3回目まで、その都度切り替わる)
- 最後の編集から**約8秒で自動的に閉じる**
- 島にマウスを乗せている間は、閉じない

---

## ⑧ 履歴から開く / 広げる

①〜⑦のどれかのあとで:

1. 概要の流れている部分を押して**履歴**を開く
2. 「編集 · invoice.ts  +1 −1」の行 (少し明るい色) を押す → その編集の差分が開く
3. 差分の画面で、島を**下に引く** → 700×480 に広がり、コードがたくさん見える
4. **Esc** で戻る (履歴 → 概要)

## ⑨ 長い返答が、途中で切れない

```
Coucou という、画面の上に出る小さな AI 監視アプリについて、次の見出しで 40 項目くらいの
長い解説を、日本語で書いてください (見出し、箇条書き、表、コードブロックを混ぜて)。
ファイルは作らず、ここに文章だけで書いてください。
```

**確認すること**
- 完了カードの「読む」→ 履歴で、**最後まで全部**読める (「…」で切れない)
- 見出し・箇条書き・表・コードブロックが**整形されて**出る

## 後片付け

```
~/coucou-test/ フォルダを、中のファイルごと削除してください (rm -r)。
```

(権限確認で、危険の警告 (赤) が出るはずです。これも確認項目です。許可すると消えます。)
