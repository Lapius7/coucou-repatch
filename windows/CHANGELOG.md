# 変更履歴

公開するバージョンごとの変更点です。同じ内容を GitHub の Releases にも載せます
(手順は [docs/RELEASING.md](docs/RELEASING.md))。新しい順です。

## [未リリース]

- **修正**: 閉じたノッチのまわり (数十ピクセル) で、クリックが吸われて、下にあるウィンドウを触れない問題。
  判定の余白を 14px から 3px に減らしました。
- **追加**: 閉じたときの形を、**細いバー**にできます (島のミニ設定パネル、設定の「一般」→「閉じたときの形」)。
  画面の上端から少し浮いた、横長の丸い線だけが残ります (iPad のホームバーのような形)。色は、**動いている AI セッションの色**を使ったグラデーションが、止まらずに流れます。確認待ち (橙)・エラー (赤)・完了 (緑) のときは、その色になります。
  バーの上 (画面の上端まで) と左右の余白は、すべてクリックに反応します。閉じるときは、島が小さくなりきってからバーに変わります
  (青: 作業中、紫: 考え中、橙: 確認待ち、赤: エラー、緑: 完了)。

## [1.1.0] — 島の大きさとホバーの設定

- **追加**: **島の大きさ**を変えられます (80%〜150%)。島のミニ設定パネルと、設定の「一般」から選べます。
  小さな画面や、高解像度のモニターでの見え方を合わせられます。

- **追加**: 使用率の数字にマウスを乗せたときの表示を、設定の「一般」→「ホバーの表示」で変えられます。
  アカウントのメールは、そのまま / 一部を隠す / 表示しない から選べます。Windows・WSL の区別、プラン名、
  5時間と週間の上限、リセット時刻、最終更新を、それぞれオン・オフできます。設定の下にプレビューが出ます。

## [1.0.1] — 不具合の修正と整理

- **修正**: 設定の「接続」で、停止中だった WSL が起動したあと、スイッチがオフのまま表示される問題。
- **変更**: プランの上限を `/usage` で取りにいく間隔を、10分から30分にしました (Claude Code を使っている間は、
  返答のたびに自動で更新されるので、変わりません)。
- **整理**: 使われていないコード (古いフック用の処理、ファイルを飲み込む演出の画面など) を削除。
  自動テストを追加 (`npm test`、`cargo test --lib`)。
- **修正**: 使わずにしばらくすると、小さなノッチが画面から消えてしまう問題。いまは**ノッチを常に表示**します
  (設定の「ノッチを常に表示」で、以前のように隠れる動きに戻せます)。

## [1.0.0] — 最初の公開

[Louis-CFM/coucou](https://github.com/Louis-CFM/coucou) の Windows 版 0.1.1 からの Fork として、最初に公開するバージョンです。
元との違いは**すべて** [RELEASE_NOTES.md](RELEASE_NOTES.md) にあります。主なもの:

- ファイル編集の差分画面 (色つき、行番号つき、コマンドの出力つき)
- プランの上限 (5時間 / 週間) の表示
- Windows と各 WSL をつなぐ、アプリ内のセットアップ (差分を見てから書き込み、アンインストールで解除)
- 履歴ビュー (Markdown 描画)、島を大きく広げる操作、島を左右にドラッグしてタブ (ホーム / チャット / 設定) を切り替え、ピンで開いたままにする
- 権限まわり: 「常に許可」、危険なコマンドの検出、ホットキー、島から Claude の質問に答える
- 右クリックのメニュー、トレイのダブルクリックで表示 / 非表示
- ファイルのドロップ: どの画面でも、島が閉じていても。画像のプレビュー
- English / 日本語

**削除**: サービス連携 (Stripe、GitHub、Vercel、n8n、Resend、Notion、Cal.com)、macOS / iPhone 版のファイル、配布用のワークフロー。
