# Coucou for Windows — repatch

[Louis-CFM/coucou](https://github.com/Louis-CFM/coucou) の Fork です。元の Windows 版 **0.1.1**
(`windows/`、コミット `83708fe`) から始めました。このページは、**元との違いをすべて**まとめています。
バージョンごとの変更は [CHANGELOG.md](CHANGELOG.md) にあります。

> ソースのみの公開です。「Coucou」の名前、Mochi のキャラクター、アイコン、サウンドは Louis Raillé のものです
> ([LICENSE-ASSETS.md](../LICENSE-ASSETS.md))。インストーラーは配布しません。自分でビルドしてください
> ([README](README.md) を参照)。

## ひと目で

| 分野 | できること |
|---|---|
| **ファイル編集** | 差分画面: Claude が何を変えたかを、色つき・行番号つきで、そのターンのステップや、直前のコマンドの出力と並べて見られる |
| **プランの上限** | 5時間と週間の使用率を島に表示。Windows と WSL のアカウントを分けて扱う |
| **セットアップ** | 1つの画面で、Windows と**すべての WSL** の Claude Code をつなぐ。初回のあいさつ画面。きれいに解除できるアンインストール |
| **履歴** | セッションの発言と作業を読み返せる (Markdown 描画)。島を大きく広げられる |
| **権限** | 「常に許可」のルール、危険なコマンドの検出、押し間違いに強いボタン、ホットキー、島から Claude の質問に答える |
| **日常** | セッションごとのピル、通知、使用量、島の中の設定パネル、全画面アプリの判定、English / 日本語 |

## 追加

### ファイル編集の差分 (ライブ差分画面)
- Claude がファイルを編集すると、**何が変わったか**が見られます。左に Mochi・セッション名・ステップ
  (`読み取り ✓ / 編集 ✓ / 実行 ◐ / 完了`)、右に**ファイルごとのタブ** (直近4つ、拡張子の札つき)、`+N −M`、
  パス、**色分けしたコード** (削除は赤の取り消し線、追加は緑、行番号、前後3行) が出ます。長い編集は160行で
  切って「… ほか N 行」と出ます。
- コードの下に、**直前のコマンドの出力** (`npm test` など) が出ます。`PASS` / `✓` の行は緑、`FAIL` / `✗` の行は赤。
  出力は**スクロールでき**、開いた直後は一番下 (結果の部分) を表示します。島を下に引くと大きく (700×480) なり、
  もっと見えます。
- 入口は3つ: 概要の**「差分 +3 −1」**ボタン、**履歴の「編集 · ファイル名」の行**を押す、
  **設定 →「ファイル編集をリアルタイム表示」** (既定はオフ) をオンにして、編集のたびに島が8秒だけ開く
  (マウスが乗っている間は閉じません)。
- **‹ 2/3 ›** で、同じファイルの複数の編集を順に見られます。**戻る / Esc** は、差分を開いた**元の画面**に戻ります。
  履歴から開いたなら、履歴は広げたまま、スクロール位置も元のままです。
- ファイルが3つ以上のときは、開いているタブだけ名前を出します (名前が1〜2文字に切れるのを避けます)。
- `Edit`、`MultiEdit`、`Write`、`NotebookEdit` に対応。行番号は、編集後のファイルを読んで探します
  (Windows のパスは直接、WSL のパスは `wsl.exe` 経由、テキスト400KBまで)。
- **機密ファイルは出さず、読みもしません**: `.env`、`.ssh`、認証情報、`.claude/settings` などは
  「非表示: 機密ファイルです。」と出ます。Rust 側でも同じ読み取りを断ります。`..` を含むパスも断ります。
- 中継は今まで `tool_response` を全部捨てていましたが、**Bash / PowerShell のものだけ**残すようにしました。

### プランの上限 (5時間と週間)
- **5時間**と**週間**の上限をどれだけ使ったか、いつリセットされるかを、島に出します。閉じた島
  (`WSL 5h 59% 07:29 · 週 21%`)、開いたときのヘッダー、空の概要のバーの3か所です。
- Claude Code がステータスラインのコマンドに渡すデータを使います (Pro / Max)。ログイン情報やトークンは
  読みません。
- **Windows と WSL は分けて**扱います (別のアカウントのことがあるため)。**設定 → 上限を出す Claude** で、
  *自動* (表示中のセッション)、*Windows*、*WSL* を選べます。数字にマウスを乗せると、アカウントのメールと
  プランが出ます (`claude auth status` で読みます)。
- 起動時に、最初の返答を待たずに取りにいきます (`claude -p "/usage"`。モデルは呼びません)。
- 今のステータスラインは、これまで通りに表示されます。中継はその前に挟まり、オフにすると元に戻ります。

### アプリ内のセットアップ: 接続
- **設定 → 接続** が、`settings.json` の手編集やスクリプトの手実行に代わります。Windows に1枚、**各 WSL** に
  1枚のカードがあり、それぞれスイッチが2つ: *Claude Code* (フック) と *プランの上限* (ステータスライン)。
- **「適用…」**は、差分そのものと、取るバックアップを見せ、クリックしてはじめて書き込みます。差分のあとに
  ファイルが変わっていたら、何も書き込みません。バックアップは毎回、日付つきで取ります。読めない、または
  JSON として正しくない `settings.json` は、絶対に上書きしません。ほかのツールのフック、あなたのステータスライン、
  あなたが付けたマッチャー (`^(?!AskUserQuestion$).*` など) には触れません。
- WSL のファイルは `wsl.exe` 経由 (Claude Code を動かしているのと同じ Linux ユーザー) で読み書きし、
  権限もそのままにします。**停止中の WSL は、見るだけでは起動しません**。「確認する」を押したときだけです。
  ウィンドウが前面に戻るたびに、一覧を読み直します。
- **初回起動**: つなげられるものがすべてオンの状態でセットアップが自動で開きます。すでにつながっている人には
  出ません。
- **アンインストール**: 手動で実行すると、*Claude Code の設定からも Coucou を外しますか?* と聞きます
  (別に、*設定と保存した API キーも消しますか?* も。既定は「いいえ」)。サイレント実行と更新では、
  どちらにも触れません。コマンドラインの `coucou.exe --disconnect` / `--purge` でも同じことができます。
- `install-from-source.ps1` で、ビルドからインストールまでをコマンド1つで (`-Light` で軽くできます)。

### 履歴の画面
- 概要の流れている部分を押すと、**セッションをさかのぼって読めます**: あなたの質問、実行したすべてのツール
  (シェルコマンドは全文)、Claude の返答 (**全文**、約3万文字まで。中継は以前、数百文字で切っていました)。
- 返答は **Markdown として描画**します: 見出し、太字・斜体・取り消し線、インラインコード、コードブロック、
  入れ子のリスト、表、引用、区切り線、`http(s)` のリンク。ライブラリも HTML も使いません (すべて
  `textContent` で組み立てるので、返答の中の `<script>` はただの文字になります)。
- 一番下を見ているときは新しい行に付いていき、上を読んでいるときは動かず、「↓ Latest」も出ます。
  **戻る** (または Esc) で1つ上へ。
- **島を下に引く** (履歴、権限確認、質問、チャット) と **700×480** に広がり、上に引くとまず戻り、もう一度で閉じます。

### 権限と質問
- **常に許可 (Always)**: この種類の依頼を、今後は許可します。ルールは、コマンド+サブコマンド (`npm run`) 単位、
  編集はフォルダ単位、`Read` / `Glob` / `Grep` / `LS` はツール単位。設定で一覧と削除ができます。
  `; && | > <`、バッククォート、`$(` を含むコマンドは、ルールになりません。
- **危険コマンドの検出**: 再帰削除、`sudo`、force push、`git reset --hard`、ダウンロードして実行、`iex`、
  ディスクやレジストリの操作、`shutdown`、`npm publish`、`.env` / `.ssh` / 認証情報 / `.claude/settings` の編集は、
  赤いカード、理由つきで、「常に許可」は出ません。ルールのパスに `..` や相対パスがあるものは断ります。
- 押し間違い対策: コマンドの全文 (3行、広げると16行)。表示から0.35秒 (危険なときは0.9秒) は許可 / 常に許可が
  押せないので、別の操作の途中でカードが出ても、誤って許可しません。
- **島から Claude の質問に答える** (`AskUserQuestion`): 選択肢、複数の質問を順に、複数選択は *Send*、
  *Terminal* で端末に戻す。*実験的です。「既知の制限」を参照。*
- **グローバルホットキー** (設定で変更可。`Ctrl+Alt+…`): 開閉 `J`、許可 `Y`、拒否 `N`、選択肢 `1`〜`4`、
  画面について質問 `S`。ほかのアプリと衝突した組み合わせは警告が出て、ほかは動きます。
- **画面について質問** (`Ctrl+Alt+S`): カーソルのあるディスプレイを PNG で保存し、チャットの質問に添えます。
  質問を送るまで、何も送られません。

### セッションと島
- **セッションごとにピルが1つ** (名前はフォルダ名、`· WSL` つき、色は自動)。クリックしても**位置は動かず**、
  フォーカス中のものが光ります。VS Code は出しません。セッションが1〜2つなら、状態と時間
  (`working · 0:07`、`needs you`、`done`) つきの全幅の行になります。
- 考え中の経過時間 (`0:22`) と、完了カードの時間 (`finished · 1:01`)。完了カードは自動で閉じます
  (既定6秒。マウスが乗っている間は待ちます)。
- 完了カードに、Claude の最後のメッセージの1行目と、要約 (`2 files edited · 3 commands`) を出します。
- **今日の使用量** (ターン数、時間、ファイル数、コマンド数。14日分、設定には直近7日) — フックのイベントだけから数えます。
- **通知**: サウンド、Windows の通知、両方、なし。完了、権限確認、エラーが対象です。
- **ファイルのドロップ**: ドロップ専用のタブをなくしました。どの画面でも、島が閉じていても、ファイルを掴んで
  島の上 (閉じているときは画面の上端の中央) へ持っていくとドロップ画面が開き、離れると元に戻ります。
  ドロップすると、確認のカードも飲み込む演出もなく、そのファイルについて質問できる画面がすぐ開きます。
  反応するのはノッチのまわりと島の上だけで、そのほかの場所は下にあるアプリにドロップできます。
  質問画面のファイルは、**クリックすると外せます**。画像は大きめの**プレビュー**になり (ファイル名は画像の上に小さく)、
  **クリックで大きく表示**、右上の「×」か**左右にドラッグ**で外せます。
- **ピン** (ヘッダーの右上): 押すと、島が自動で閉じなくなります (マウスが離れても、完了カードの自動で閉じる動きも、
  Esc も、上へのドラッグも効きません)。もう一度押すと元に戻ります。
- **長い文**: 完了カードの1行目が長いと、島が縦に伸びて収めます (最大4行)。
- **右クリックのメニュー** (島とトレイのアイコン、同じ内容): Coucou を開く、Claude の上限を更新、設定、
  ノッチを非表示 / 表示、Coucou を再起動、ログのフォルダを開く、終了。**トレイのアイコンをダブルクリック**
  すると、ノッチの表示 / 非表示が切り替わります。
- **エラーカード**: Claude Code が返した理由 (「利用制限に達しました」など) を出し、長い文でも2行に収めます。
- **島の中のミニ設定パネル** (歯車): サウンドと音量、通知の方法、表示する画面、自動で閉じる、完了カードのタイマー、
  差分の自動表示、プランの上限、自動起動、そして島も小さくなる「設定を開く」ボタン。
- **English / 日本語** (言語の足し方も簡単): **設定 → 一般 → 言語**。
- **API キーなしのチャット**: キーがなければ、チャットは `claude` CLI で答えます (Windows を先に、次に WSL)。
  会話は `--session-id` / `--resume` で続け、ツールは Web 検索と取得に限ります。
- **全画面アプリの判定**: ゲーム、動画、プレゼンが画面を占めている間は、島は隠れ、フォーカスを奪わず、
  権限確認は端末にそのまま戻します。全画面アプリの前に別のウィンドウがあるときは、島が出ます。
  別のモニターのゲームでは隠れません。

## 変更

- 完了カードのボタンは **OK** だけ (「Open terminal」は廃止)。「↗ VS Code で開く」ボタンも削除しました。
- 考え中の行が重ならなくなりました。ticker は、切り替えたセッションに追従し、空行の代わりに
  「Waiting for a prompt」と出します。
- Bash / PowerShell のコマンドは、流れるステップに入れません (先頭40文字がいつも `cd … &&` だったため)。
  全文は履歴にあります。
- `SubagentStop` が、完了メッセージを「subagent done」で上書きしなくなりました。
- 島を**左右にドラッグ**すると、タブ (ホーム / チャット / 設定) が切り替わります (権限確認の待機中は切り替わりません)。
- 島を**上にドラッグ**すると閉じます。指に追従し、バネで戻ります (権限確認の待機中は閉じません)。
- 中継が残す文字数が増えました: 返答は96,000バイトまで、プロンプトとファイルの中身は24,000まで。
- 設定ウィンドウに、接続、ホットキー、記憶した許可、使用量、プランの上限のセクションが増えました。
- 閉じた島を広げました (288 → 328 px)。プランの上限が収まるようにするためです。
- WSL のフックは、Windows の中継のパス (`/mnt/c/…`) で書き込みます。使うプログラムは Windows の中継だけです。

## 削除

- リリースとインストーラーの公開用ワークフロー (元の Windows と Linux のパッケージ作成、macOS のタグビルド確認)。
  `npm run pack` は、自分の PC 用のインストーラーを作る機能として残っています。
- `coucou_statusline.py`: アプリがその役目を引き継ぎました。

- **サービス連携** (Stripe、GitHub、Vercel、n8n、Resend、Notion、Cal.com の7つ): ピル、カード、定期的な問い合わせ、
  設定画面の「連携」、保存する API キー、n8n を開くボタンをすべて削除しました。Claude Code とは関係のない機能だったためです。
  以前保存したキーは、アンインストール時の「保存した API キーも消す」で消えます。

## 修正

- 中継が返答を (日本語で) 約660文字で切っていた: 項目ごとに切るようにしました。
- 別のセッションに切り替えても、前のセッションのメッセージが ticker に残っていた。

## セキュリティ

- API キーは Windows の資格情報マネージャーに置きます。島は、キーがあるかどうかを聞けるだけです。
- 許可ルールは、パスの抜け道 (`..`、相対パス) を断ります。秘密を読む `Read` は危険として扱います。
- WSL のランチャーは引数を `"$@"` で渡し、ダッシュや空白で始まる値を断ります。ステータスラインとフックの
  コマンドは、パスがコマンドにならないよう引用符で囲みます。
- `settings.json` を置き換えるのは、見た差分のあとだけで、バックアップを取り、アトミックに、権限を保って行います。
  一時ファイルは、作られた瞬間から非公開です。
- テレメトリはありません。通信は、あなたが設定したサービスだけです。

## 既知の制限

- **署名なし・配布なし。** 自分でビルドしてください。
- **島からの `AskUserQuestion` は実験的です。** うまく動かないときは、Coucou の `PreToolUse` と
  `PermissionRequest` の項目に、マッチャー `^(?!AskUserQuestion$).*` を付けてください。もう一度「適用」しても
  Coucou はそれを残し、質問はいつも通り端末で答える形になります。
- プランの上限は **Pro / Max** のサブスクリプションと、**ターミナルで動く** Claude Code が必要です
  (デスクトップ版は報告しません)。
- 構文の色は、1行ずつの簡易版です (複数行にまたがる文字列は追いません)。
- ルールのフォルダの中のシンボリックリンクやジャンクションは、画面側からは見えません。ルールは、
  自分が管理するフォルダにだけ付けてください。
- 接続画面とアンインストールの質問は、いちばん新しい部分で、テストが最も少ないです。
